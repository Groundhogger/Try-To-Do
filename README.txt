Deployment:
Back up the current General repository, then upload the extracted contents of this folder to the repository root. Do not upload the ZIP itself.
For an existing iPhone home-screen shortcut, delete the old shortcut and add the site to the Home Screen again after the new deployment. iOS can retain an old icon independently of the website cache.
